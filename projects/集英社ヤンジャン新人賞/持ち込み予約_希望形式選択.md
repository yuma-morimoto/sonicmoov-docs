## 1. 目的

持ち込み予約の LIFF 画面（入力フォーム）にて、ユーザーが「対面」または「リモート」の希望形式を選択できるようにし、確認画面にもその選択内容を反映する。

## 2. 対象画面

- 持ち込み予約 LIFF 画面（入力フォーム／確認画面）

## 3. 機能仕様

### 3.1 入力フォーム — 希望形式ボタンの追加（INNER-87）

- 入力フォームに「希望形式」セクションを追加し、「対面」「リモート」の 2 つの選択ボタンを **横並び** で配置する。
- 初期状態は両ボタンとも「未選択（グレーアウト）」とする。
- ユーザーがいずれかのボタンを選択すると、LINE グリーンにハイライトする（選択状態の視覚的フィードバック）。
- 必須項目とし、他の必須項目と同様に必須マーク（赤いポッチ）を表示する。

### 3.2 バリデーション（INNER-87）

- どちらのボタンも選択されていない状態で「この日時で予約」等の送信リクエストを行おうとした場合、エラーテキスト（例：「希望形式を選択してください」）を表示し、送信を抑止する。
- 「対面」「リモート」のいずれかが選択された時点で、エラー表示は自動的に解消する。

### 3.3 確認画面への表示（INNER-88）

- 確認画面に、入力フォームで選択した「希望形式」の情報を反映する。
- 表示内容：
  - 項目名：「希望形式」
  - 値：選択された「対面」または「リモート」

## 4. 状態と UI のまとめ

| 状態 | 表示 |
| --- | --- |
| 初期表示 | 2 ボタンとも未選択（グレーアウト）／必須マークあり |
| 「対面」選択 | 「対面」ボタンが LINE グリーンでハイライト、「リモート」は未選択（グレーアウト） |
| 「リモート」選択 | 「リモート」ボタンが LINE グリーンでハイライト、「対面」は未選択（グレーアウト） |
| 未選択で送信 | 「希望形式を選択してください」等のエラーテキストを表示、送信をブロック |
| 送信後（確認画面） | 選択された希望形式を「対面」または「リモート」として表示 |
